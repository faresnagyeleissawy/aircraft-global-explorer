World 3D Explorer

Controls

↑ / ↓Climb / dive
← / →Bank and turn
ShiftMore throttle (W / S: throttle up / down)
Mouse wheelZoom in and out
ClickShow the name and address of that building or spot
Double-clickFly to that spot on the map

V switches between chase and inside view. R goes back to the start point. B flies to Burj Khalifa. H hides this.

Search takes you to any place in the world. "Route" draws the road between two places.

Cesium ion access token

The map data comes from your free Cesium ion account. Open ion.cesium.com/tokens, copy the Default token and paste it here. It is saved only in this browser.
